Usage

Configure your MCP client to send the credential in the Authorization header.

Example MCP client configuration:

{
  "mcpServers": {
    "server-name": {
      "url": "{{ mcp_endpoint }}",
      "headers": {
        "Authorization": "Bearer <client_id>:<client_secret>"
      }
    }
  }
}

Replace <client_id> and <client_secret> with the values shown when you created the credential.
